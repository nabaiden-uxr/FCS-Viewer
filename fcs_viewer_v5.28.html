Thresholds: POSITIVE: SI ≥ 1.0 AND nMFI ≥ 2.0  |  NEGATIVE: SI < 0.5 OR nMFI < 1.2  |  BORDERLINE: otherwise.
nMFI = Median(test)/Median(ctrl). SI = (Median(test)−Median(ctrl))/(2×SD(ctrl)).
%Pos threshold = 99th percentile of negative control. All statistics on raw (unscaled) values.
Cell density = event count / acquisition volume (events/µL). Total uses all events; gated uses events passing the 3-Plot gate. Volume auto-detected from flow rate × acquisition time, or FCS metadata keyword. Edit in the left panel.
Ref: Maecker & Trotter 2006; Chan et al. 2012; Hulspas et al. 2009.

Export Visualisation Data

Exports the data behind the current plot: event-level values for scatter and 3-plot panels, binned counts for histograms. CSV output is long-format and reads directly into R (read.csv / ggplot2); Excel output contains the same table plus a Meta sheet. When a gate is active, the gate definition (type, channels, scales, coordinates, n gated, percent gated) is included as a Gates sheet (Excel) or a second _gates.csv file, alongside the per-event InGate flags in the data table.
